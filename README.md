# B&J Digital Studio

A responsive portfolio website for B&J Digital Studio, created with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — colors, layout, responsive styling, and project preview designs
- `script.js` — project cards, category filters, and mobile navigation

## Open in VS Code
1. Extract the ZIP file.
2. Open VS Code.
3. Choose **File → Open Folder** and select the `bj-digital-studio` folder.
4. Open `index.html`.
5. If you have the Live Server extension, right-click `index.html` and choose **Open with Live Server**. Otherwise, double-click `index.html` in File Explorer to open it in your browser.

## Before publishing
1. In `script.js`, update each project's `url` when you have a live demo. Leave it as an empty string if the project is not published yet.
2. In `index.html`, replace `hello@example.com` with your business email address.
3. Replace the Facebook URL with your actual B&J Digital Studio page.
4. Make sure the portfolio only claims projects and services you can actually provide.

The Google Fonts import needs an internet connection. If offline, the website will use fallback fonts.
